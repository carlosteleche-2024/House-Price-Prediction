# Fase 2 - House Price Prediction

## Proyecto Integrador
**Asignatura:** Modelos y Simulación de Sistemas I  
**Universidad de Antioquia**

## Objetivo
Esta fase continúa el modelo de predicción de precios de viviendas desarrollado en la Fase 1. Se incorporan las correcciones derivadas de la retroalimentación recibida y se prepara el modelo para su ejecución reproducible mediante scripts, pruebas automatizadas y contenedores Docker.

## Cambios respecto a la Fase 1
Durante esta fase se abordarán, entre otros, los siguientes aspectos:

- Selección del modelo mediante validación sobre los datos de entrenamiento, reservando el conjunto de prueba para la evaluación final.
- Revisión de viviendas repetidas entre las particiones de entrenamiento y prueba.
- Revisión de variables altamente correlacionadas.
- Documentación de la fuente y características del dataset.
- Documentación de los datos faltantes simulados utilizados en la Fase 1.
- Definición explícita de las versiones de las dependencias.
- Implementación de scripts para entrenamiento y predicción.
- Versionamiento del modelo entrenado.
- Pruebas automatizadas con pytest.
- Contenerización mediante Docker.
